### Implementation Reference Blueprint (provisional; no preselected page design)
- **Target architecture:** static HTML + CSS + small vanilla JS; no runtime dependency/build system unless later R1 direction or verified requirement benefits from one. Aligns Starter's static-first scope and keeps security/supply-chain surface small.
- **Document shell/metadata:** semantic `header/nav/main/section/footer`; one H1; meaningful H2 hierarchy; title/description/canonical/social metadata added only once final hostname is known; no invented canonical host now.
- **Navigation:** sticky/floating header for long single page; native anchor links; mobile menu button with `aria-expanded`, `aria-controls`, Escape close and focus return; active section cue only if it adds orientation and remains legible. Test 320px touch, keyboard and scroll states.
- **Layout/tokens:** CSS custom properties for type scale, spacing, width, colour and surfaces; fluid typography/layout with grid/flex; intentional small/medium/wide compositions, not only stacked desktop grid; no CSS framework necessary by default.
- **Interactions:** native details/summary for FAQ if selected; no client-side-only forms claiming submission, no fake inquiry success, no fake protected/case study access; external links only when confirmed endpoints exist.
- **Motion:** mostly static by default; optional reveal only for meaningful hierarchy, with `prefers-reduced-motion` fallback and no essential hidden content.
- **Accessibility/performance:** skip link, visible focus, landmarks, proper labels/alt, sufficient contrast, keyboard controls, target size, avoid remote JS/font reliance unless justified; optimise any actual screenshots.
- **Security:** no secrets/forms/data collection; audit final output and third-party requests; add host-specific headers only when hosting provider is selected and CSP sources are known. No copied security configuration from a mismatched stack.
- **Rights:** code candidates' licenses were verified as MIT for inspected repository-root file and applicable full project; if any code is copied later preserve applicable copyright/license notice and audit every asset/font/icon/dependency separately. For current project code, disposition remains learn-only; independently author implementation.
- **Research boundary:** this is a pattern blueprint only. It does not prescribe color, typography, composition, section design, hero imagery or any R1 visual direction.
